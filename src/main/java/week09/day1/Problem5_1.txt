[추가 연습 문제 5-1 가이드 메모장]

[문제]
정수(Integer)를 입력받아 그 수의 제곱(square, x * x)을 반환하는 람다식을 작성하고,
이를 자바의 표준 함수형 인터페이스인 Function<Integer, Integer> 타입의 변수에 저장하세요.
이후, for문을 사용하여 1부터 5까지의 숫자를 대입해 각각의 제곱 결과를 출력하는 코드를 완성해 보세요.

[힌트 및 기술 가이드]
- Function<T, R> 은 입력 타입 T와 반환 타입 R을 가집니다.
- 여기서는 정수를 입력받아 정수를 반환하므로 Function<Integer, Integer> 가 됩니다.
- 람다식은 다음과 같이 변수에 담습니다:
  Function<Integer, Integer> square = x -> x * x;
- 호출할 때는 함수형 인터페이스의 추상 메서드인 `apply()`를 사용합니다:
  int result = square.apply(i);
