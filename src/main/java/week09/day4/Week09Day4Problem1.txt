[문제]
점수 리스트의 평균을 mapToInt와 average()를 활용해 구하세요.

[사용자 작성 코드]
package week09.day4;

import java.util.*;

/**
 * [연습 문제 1] 점수 평균 구하기
 * 문제: 점수 리스트의 평균을 mapToInt와 average()를 활용해 구하세요.
 */
public class Problem1 {
    public static void main(String[] args)
    {
        // TODO
        List<Integer> nums = new ArrayList<>(Arrays.asList(1,2,3,4,5));

        OptionalDouble avg = nums.stream().mapToInt(Integer::intValue).average();
        System.out.println(avg);

        //Optional<Double>가 안되는이유 그냥 자동완성에 있어서 OptionalDouble씀
    }
}

[현재 코드 특징]
스트림을 생성하고 `mapToInt`를 통해 IntStream으로 변환한 뒤 `average()`를 호출하는 핵심 로직을 정확히 구현했습니다.

[Better Code]
package week09.day4;

import java.util.*;

public class Problem1 {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5);

        // orElse() 또는 getAsDouble()을 사용해 실제 값을 꺼냅니다.
        double avg = nums.stream()
                         .mapToInt(Integer::intValue)
                         .average()
                         .orElse(0.0); 
                         
        System.out.println(avg);
    }
}

[기술적 해설]
1. OptionalDouble 출력 문제
현재 코드에서 `System.out.println(avg);`를 실행하면 실제 값인 `3.0`이 아니라 객체 형태인 `OptionalDouble[3.0]`과 같이 출력됩니다. 실제 숫자 값을 얻으려면 `.getAsDouble()`이나 빈 값일 경우를 대비한 `.orElse(0.0)`을 사용하여 값을 안전하게 꺼내야 합니다.

2. Optional<Double>이 아닌 OptionalDouble을 사용하는 이유 (질문 답변)
`mapToInt`를 사용하면 일반 `Stream<Integer>`가 아니라 기본형(primitive type) 특화 스트림인 `IntStream`으로 변환됩니다. `IntStream`의 `average()` 메서드는 성능 최적화(불필요한 Autoboxing/Unboxing 방지)를 위해 제네릭 객체 래퍼 클래스인 `Optional<Double>` 대신, 기본형 `double`을 감싸는 전용 클래스인 `OptionalDouble`을 반환하도록 설계되어 있습니다.

3. 리스트 초기화 팁
단순히 고정된 값을 읽고 스트림 연산만 할 목적이라면 `new ArrayList<>(Arrays.asList(...))` 대신 `Arrays.asList(...)` 또는 `List.of(...)`만 사용하는 것이 메모리 효율 측면에서 더 좋습니다.
