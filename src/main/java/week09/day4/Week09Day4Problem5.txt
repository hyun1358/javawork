[문제]
배열 {3, 7, 1, 9, 2}에서 스트림의 max() 메서드를 활용하여 최대값을 구하고 출력하세요.

[사용자 작성 코드]
package week09.day4;

import java.util.Arrays;
import java.util.OptionalInt;

/**
 * [연습 문제 5] 최대값 (max)
 * 문제: 배열 {3, 7, 1, 9, 2}에서 스트림의 max() 메서드를 활용하여 최대값을 구하고 출력하세요.
 */
public class Problem5 {
    public static void main(String[] args)
    {
        // TODO
        int[] arr = {3,7,1,9,2};

        OptionalInt max = Arrays.stream(arr).max();
        System.out.println(max);

        //왜 Stream<T>를 안쓰고 OptionalInt를 쓰는가
    }
}

[현재 코드 특징]
`Arrays.stream(arr)`을 통해 배열을 스트림으로 올바르게 변환했고, `max()` 메서드를 사용하여 최대값을 찾는 로직을 정확히 작성했습니다.

[Better Code]
package week09.day4;

import java.util.Arrays;

public class Problem5 {
    public static void main(String[] args) {
        int[] arr = {3, 7, 1, 9, 2};

        // orElse() 또는 getAsInt()를 사용해 실제 값을 꺼냅니다.
        int max = Arrays.stream(arr)
                        .max()
                        .orElse(-1); 
                        
        System.out.println(max);
    }
}

[기술적 해설]
1. OptionalInt 출력 문제
현재 코드대로 `System.out.println(max);`를 실행하면 실제 값인 `9`가 아니라 `OptionalInt[9]` 형태의 객체 자체가 출력됩니다. 스트림 연산 결과를 실제 정수 값으로 사용하려면 `.getAsInt()` 또는 값이 없을 경우를 대비한 `.orElse(-1)` 등으로 값을 직접 꺼내주어야 합니다.

2. 왜 Stream<T>가 아닌 OptionalInt(IntStream)가 쓰이는가? (질문 답변)
`arr`은 기본형(primitive type)인 `int[]` 배열입니다. Java에서 `Arrays.stream(int[])`을 호출하면 제네릭 객체 스트림인 `Stream<Integer>`가 아니라, 기본형 전용 스트림인 `IntStream`이 반환됩니다.
`IntStream`은 내부적으로 `int` 값을 그대로 다루기 때문에, `Integer` 객체로 변환(Boxing)하는 비용이 발생하지 않아 메모리와 연산 속도에서 성능상 훨씬 유리합니다.
마찬가지로 `IntStream.max()`의 결과 역시 제네릭 `Optional<Integer>`가 아니라, 박싱을 피하기 위해 설계된 전용 클래스인 `OptionalInt`를 반환하는 것입니다.
