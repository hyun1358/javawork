[문제]
1~45 사이 난수를 HashSet에 저장하여 자동으로 중복 없이 6개가 모일 때까지 반복하세요.

[사용자 작성 코드]
package week08.day4;

import java.util.HashSet;

public class Problem4 {
    public static void main(String[] args)
    {
        // TODO

        HashSet<Integer> lotto = new HashSet<>();
        while(lotto.size() < 6)
        {
            int radom = (int)(Math.random()*45)+1;
            lotto.add(radom);
        }

        System.out.println(lotto);
    }
}

[현재 코드 특징]
- 중복을 제거하면서 무작위 번호를 추출하는 난수 생성 알고리즘 `(int)(Math.random()*45)+1`을 수학적으로 완벽하게 이해하고 정확하게 작성했습니다.
- `lotto.size() < 6` 조건을 지닌 `while` 루프를 사용해 고유한 번호가 6개 꽉 찰 때까지 효율적으로 순회하는 제어 흐름을 구현했습니다.

[Better Code]
package week08.day4;

import java.util.HashSet;
import java.util.Set; // Set 인터페이스 추가

public class Problem4 {
    public static void main(String[] args)
    {
        // 구현체 타입(HashSet) 대신 인터페이스 타입(Set)으로 변수를 선언합니다.
        Set<Integer> lotto = new HashSet<>();
        while(lotto.size() < 6)
        {
            int random = (int)(Math.random() * 45) + 1; // 오타 수정 (radom -> random)
            lotto.add(random);
        }

        System.out.println("로또 번호: " + lotto);
    }
}

[기술적 해설]
1. 인터페이스 다형성 선언 (Set 사용):
   - `HashSet<Integer>` 객체를 받을 때 변수형을 `Set<Integer>`로 선언하는 것은 Java 실무의 표준 관례입니다.
   - 나중에 로또 번호를 정렬하여 보고 싶어서 정렬 기능이 들어있는 `TreeSet`으로 내부 구조를 바꾸고 싶을 때, 변수형이 `Set`으로 선언되어 있다면 좌측 코드는 하나도 건드리지 않고 우측의 생성자(`new TreeSet<>()`)만 살짝 바꿔주면 되기 때문에 극도로 효율적인 코드가 됩니다.
2. 변수명 가독성 개선:
   - 사용자 코드의 `radom`은 간단한 철자 오타(random)로 보입니다. 코드 규모가 커질수록 변수의 철자를 바르게 맞추는 것이 협업과 유지보수에 매우 큰 도움이 됩니다.
