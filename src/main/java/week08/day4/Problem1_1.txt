[문제]
중복된 이름들이 들어있는 문자열 배열 {"Kim", "Lee", "Kim", "Park", "Lee", "Choi"} 가 있습니다. 이 배열에서 중복을 제거한 고유한 이름들을 추출하고, 총 몇 명의 고유한 회원(이름)이 존재하는지 출력해 보세요.

[사용자 작성 코드]
package week08.day4;

import java.util.*;

public class Problem1_1 {
    public static void main(String[] args)
    {
        // TODO
        Set<String> names = new HashSet<>(Arrays.asList("Kim", "Lee", "Kim", "Park", "Lee", "Choi"));

        for(String name : names)
        {
            System.out.println(name);
        }

    }
}

[현재 코드 특징]
- `HashSet`과 `Arrays.asList()`를 적절히 혼합하여 중복된 문자열들을 한 줄로 깔끔하게 제거하며 선언했습니다.
- 향상된 for문(for-each)을 사용하여 중복이 제거된 고유한 이름들을 순회하며 잘 출력했습니다.
- 다만, 문제의 두 번째 요구사항인 **"총 몇 명의 고유한 회원(이름)이 존재하는지 출력"**하는 부분이 누락되었습니다.

[Better Code]
package week08.day4;

import java.util.*;

public class Problem1_1 {
    public static void main(String[] args)
    {
        String[] originalNames = {"Kim", "Lee", "Kim", "Park", "Lee", "Choi"};
        
        // 1. HashSet을 통해 중복 제거
        Set<String> names = new HashSet<>(Arrays.asList(originalNames));

        // 2. 고유 회원 목록 출력
        System.out.println("고유 회원 목록: " + names);

        // 3. 고유 회원 수 출력 (누락되었던 고유 회원 수 출력 구현)
        System.out.println("고유 회원 수: " + names.size() + "명");
    }
}

[기술적 해설]
1. 요구사항 완수:
   - 실제 프로그래밍 시험이나 실무에서는 문제의 모든 세부 요구사항을 꼼꼼하게 충족시키는 것이 핵심입니다.
   - 컬렉션의 크기를 반환하는 `names.size()` 메서드를 사용하면 총 고유 회원 수를 간단하게 출력할 수 있습니다.
2. 데이터와 로직의 분리:
   - 생성자 안에 직접 `Arrays.asList(...)`로 모든 요소를 하드코딩하기보다, 문자열 배열(`originalNames`)을 선언한 뒤 이를 컬렉션으로 변환하는 형태가 가독성도 높고 추후 배열 데이터만 동적으로 교체하기도 훨씬 수월합니다.
