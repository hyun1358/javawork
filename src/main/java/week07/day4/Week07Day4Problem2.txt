[문제]
[연습 문제 2] RuntimeException 상속
throws 선언이 필요 없는 언체크드 커스텀 예외를 만들고 테스트하세요.

[사용자 작성 코드]
package week07.day4;

import java.util.Scanner;

public class Problem2 {
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);
        try
        {
            int age = sc.nextInt();
            System.out.print("나이: ");
            sc.nextLine();
            checkAge(age);
        }
        catch(InvalidAgeException e)
        {
            System.out.println("오류메세지: " + e.getMessage());
            System.out.println("오류코드: " + e.getErrorCode());
        }
        finally
        {
            sc.close();
        }
    }

    public static void checkAge(int age)
    {
        if(age <= 0)
        {
            throw new InvalidAgeException("나이가 0보다 작거나 같습니다.",401);
        }
    }
    static class InvalidAgeException extends RuntimeException
    {
        private int errorCode;

        InvalidAgeException(String message, int errorCode)
        {
            super(message);
            this.errorCode = errorCode;
        }

        public int getErrorCode() { return errorCode;}
    }
}

[현재 코드 특징]
- InvalidAgeException이라는 명확한 이름의 커스텀 런타임 예외를 잘 생성했습니다.
- 입력값에 따른 예외 조건(age <= 0) 검증 로직이 훌륭합니다.

[Better Code]
package week07.day4;

import java.util.Scanner;

public class Problem2 {
    public static void main(String[] args) {
        // try-with-resources 활용
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("나이: "); // 수정: 안내 메시지가 입력을 받기 '전'에 먼저 출력되어야 합니다.
            int age = sc.nextInt();
            sc.nextLine();
            checkAge(age);
        } catch(InvalidAgeException e) {
            System.out.println("오류메세지: " + e.getMessage());
            System.out.println("오류코드: " + e.getErrorCode());
        }
    }

    public static void checkAge(int age) {
        if(age <= 0) {
            throw new InvalidAgeException("나이가 0보다 작거나 같습니다.", 401);
        }
    }

    static class InvalidAgeException extends RuntimeException {
        private int errorCode;

        InvalidAgeException(String message, int errorCode) {
            super(message);
            this.errorCode = errorCode;
        }

        public int getErrorCode() { 
            return errorCode;
        }
    }
}

[기술적 해설]
1. UI/UX 논리적 오류 수정: 기존 코드는 `sc.nextInt()`가 `System.out.print("나이: ")`보다 먼저 호출되어, 콘솔창에서 아무런 안내 없이 입력을 기다리는 "먹통" 현상처럼 보였습니다. 입력을 요구하는 안내 메시지를 입력 전에 출력하도록 순서를 수정했습니다.
2. try-with-resources: Problem1과 마찬가지로 코드를 더욱 간결하고 안전하게 만들기 위해 자원 자동 해제 구문을 적용했습니다.
