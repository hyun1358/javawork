[문제]: 부모 타입 변수를 통해 호출해도 오버라이딩된 자식 메서드가 실행됨을 확인하세요.

[사용자 작성 코드]:
public class Problem2 {
    public static void main(String[] args)
    {
        // TODO
        Parents p = new child();
        p.print();
    }

    static class Parents
    {
        void print() {
            System.out.println("나는 부모");
        }
    }

    static class child extends Parents
    {

        @Override
        void print()
        {
            System.out.println("나는 자식");
        }
    }
}

[현재 코드 특징]:
- 업캐스팅(Upcasting)을 통해 부모 변수에 자식 객체를 할당하고, 오버라이딩된 자식의 메서드가 정상적으로 호출되는 다형성의 핵심 개념을 올바르게 구현했습니다.

[Better Code]:
package week06.day3;

public class BetterProblem2 {
    public static void main(String[] args) {
        Parents p = new Child();
        p.print();
    }

    static class Parents {
        void print() {
            System.out.println("나는 부모");
        }
    }

    // 클래스 이름은 대문자로 시작하는 파스칼 케이스(PascalCase)를 적용합니다.
    static class Child extends Parents {
        @Override
        void print() {
            System.out.println("나는 자식");
        }
    }
}

[기술적 해설]:
1. 자바 네이밍 컨벤션: 자바에서 클래스의 이름은 첫 글자를 대문자로 시작하는 파스칼 케이스(PascalCase)를 따르는 것이 표준입니다. `child`를 `Child`로 변경하면 다른 개발자들도 코드를 더 쉽게 읽고 이해할 수 있습니다. 로직은 완벽합니다!
