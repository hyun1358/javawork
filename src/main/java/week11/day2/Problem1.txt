[문제]
숫자 배열을 정렬하는 Sorter 클래스에 오름차순/내림차순 전략을 주입받게 만드세요.

[사용자 작성 코드]
package week11.day2;

import java.util.Arrays;
import java.util.Collections;

public class Problem1 {
    public static void main(String[] args)
    {
        Sorter sorter = new Sorter();
        int[] arr = {13,4,56,1,2,5,6,1,3565};

        sorter.setSortStrategy(new AscendingSortStrategy());
        sorter.sort(arr);

        sorter.setSortStrategy(new DecendingSortStrategy());
        sorter.sort(arr);
    }

    interface SortStrategy
    {
        void sort(int[] arr);
    }

    static class AscendingSortStrategy implements SortStrategy
    {
        @Override
        public void sort(int[] arr)
        {
            Arrays.sort(arr);
            for(int n : arr)
            {
                System.out.print(n + " ");
            }
            System.out.println();
        }
    }

    static class DecendingSortStrategy implements SortStrategy
    {
        @Override
        public void sort(int[] arr)
        {
            Arrays.sort(arr);
            for(int i = 0; i < arr.length /2; i++)
            {
                int temp = arr[i];
                arr[i] = arr[arr.length - i -1];
                arr[arr.length - i - 1] = temp;
            }

            for(int n : arr)
            {
                System.out.print(n+" ");
            }
            System.out.println();
        }
    }

    static class Sorter
    {
        SortStrategy sortStrategy;

        public void setSortStrategy(SortStrategy s) {this.sortStrategy=s;}

        public void sort(int[] arr) {this.sortStrategy.sort(arr);}
    }
}

[현재 코드 특징]
- 사용자가 직접 오름차순과 내림차순의 정렬 인터페이스 및 구현 클래스를 만들고, 이를 Context(Sorter)에 바인딩하여 동적으로 전략을 바꾸는 전략 패턴을 잘 이해하고 설계했습니다.
- 특히 내림차순 정렬 구현 시 기본형 int[] 배열의 특성을 감안하여, Arrays.sort() 실행 후 중간점을 기준으로 대칭 교환(swap)하는 효율적인 in-place 역순 정렬을 정확하게 코딩했습니다.
- 다만, 정렬 전략(Strategy) 클래스 내부에서 직접 System.out.print를 수행하여 화면 출력 기능까지 맡기고 있습니다.

[Better Code]
package week11.day2;

import java.util.Arrays;

public class Problem1 {
    public static void main(String[] args)
    {
        Sorter sorter = new Sorter();
        int[] arr = {13, 4, 56, 1, 2, 5, 6, 1, 3565};

        // 오름차순 정렬 전략 설정 및 수행
        sorter.setSortStrategy(new AscendingSortStrategy());
        sorter.sort(arr);
        printArray(arr); // 출력 책임을 클라이언트로 분리

        // 내림차순 정렬 전략 설정 및 수행
        sorter.setSortStrategy(new DescendingSortStrategy());
        sorter.sort(arr);
        printArray(arr); // 출력 책임을 클라이언트로 분리
    }

    private static void printArray(int[] arr) {
        for (int n : arr) {
            System.out.print(n + " ");
        }
        System.out.println();
    }

    interface SortStrategy
    {
        void sort(int[] arr);
    }

    // 정렬 책임만 담당
    static class AscendingSortStrategy implements SortStrategy
    {
        @Override
        public void sort(int[] arr)
        {
            Arrays.sort(arr);
        }
    }

    // 정렬 책임만 담당 (철자 수정: Decending -> Descending)
    static class DescendingSortStrategy implements SortStrategy
    {
        @Override
        public void sort(int[] arr)
        {
            Arrays.sort(arr);
            int len = arr.length;
            for (int i = 0; i < len / 2; i++)
            {
                int temp = arr[i];
                arr[i] = arr[len - i - 1];
                arr[len - i - 1] = temp;
            }
        }
    }

    static class Sorter
    {
        private SortStrategy sortStrategy;

        public void setSortStrategy(SortStrategy s) {
            this.sortStrategy = s;
        }

        public void sort(int[] arr) {
            if (sortStrategy != null) {
                sortStrategy.sort(arr);
            }
        }
    }
}

[기술적 해설]
1. 단일 책임 원칙 (Single Responsibility Principle) 준수
   - 원본 구현에서는 `sort()` 메서드 내부에서 정렬뿐만 아니라 '출력'까지 담당하고 있었습니다. 
   - 만약 나중에 이 정렬 모듈을 모바일 화면에 그리거나 파일로 저장하는 시스템에 재사용하려고 한다면, 내부에 굳이 System.out.print 콘솔 출력이 들어 있어 재사용이 힘들어집니다. 
   - 따라서 전략 클래스는 순수하게 데이터를 정렬(데이터 가공)하는 역할만 하고, 출력은 Sorter를 사용하는 Client(여기서는 main 메서드)가 담당하도록 분리하는 것이 이상적입니다.
2. 메서드 및 클래스 명명 규칙 (Naming Convention)
   - '내림차순'은 영어로 'Descending'입니다. 코드에 기재된 'Decending' 오타를 수정하여 코드의 완성도를 높였습니다.
