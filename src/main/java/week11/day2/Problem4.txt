[문제]
유튜브 채널에 unsubscribe(구독 취소) 메서드를 추가하고 테스트하세요.

[사용자 작성 코드]
package week11.day2;

import java.util.ArrayList;
import java.util.List;

public class Problem4 {
    public static void main(String[] args)
    {
        YoubeChannel y = new YoubeChannel("자바의 정석","김작가");
        Subscribe s1 = new Subscribe("홍길동");
        Subscribe s2 = new Subscribe("이길동");
        Subscribe s3 = new Subscribe("삼길동");
        Subscribe s4 = new Subscribe("사길동");

        y.addSubscribe(s1);
        y.addSubscribe(s2);
        y.addSubscribe(s3);
        y.addSubscribe(s4);

        y.notification();

        y.removeSubscribe(s2);

        y.setTitle("자바스크립트의 정석");
        y.notification();

    }

    interface ChannelObserver
    {
        void notify(String message);
    }

    static class Subscribe implements ChannelObserver
    {
        String name;

        Subscribe(String name) { this.name = name;}

        @Override
        public void notify(String message)
        {
            System.out.println(name + "님 : " + message);
        }
    }

    static class YoubeChannel
    {
        ChannelObserver channelObserver;
        List<Subscribe> subscribes = new ArrayList<>();
        String title;
        String name;

        YoubeChannel(String title, String name) {this.title = title; this.name = name;}

        void setTitle(String title) { this.title = title;}

        void setChannelObserver(ChannelObserver c) { this.channelObserver=c;}

        void addSubscribe(Subscribe s) { subscribes.add(s); }

        void removeSubscribe( Subscribe s) { subscribes.remove(s); System.out.println(s.name+"님이 구독을 취소 하였습니다.");}

        public void notification()
        {
            String message = name+"님의 채널에서 ["+ title+"]방송을 시작합니다.";
            for(Subscribe s : subscribes)
            {
                s.notify(message);
            }
        }
    }
}

[현재 코드 특징]
- 구독자 관리를 위한 List<Subscribe> 컬렉션에서 `remove(s)` 메서드를 정확히 사용하여 옵저버를 리스트에서 제거해 구독 취소를 성공적으로 구현했습니다.
- main 메서드에서 4명의 구독자를 등록했다가 1명을 제거한 후 상태 전파가 정상적으로 줄어들어 동작하는 흐름을 일목요연하게 입증했습니다.

[Better Code]
package week11.day2;

import java.util.ArrayList;
import java.util.List;

public class Problem4 {
    public static void main(String[] args)
    {
        YoutubeChannel channel = new YoutubeChannel("자바의 정석", "김작가");
        Subscriber s1 = new Subscriber("홍길동");
        Subscriber s2 = new Subscriber("이길동");
        Subscriber s3 = new Subscriber("삼길동");
        Subscriber s4 = new Subscriber("사길동");

        channel.subscribe(s1);
        channel.subscribe(s2);
        channel.subscribe(s3);
        channel.subscribe(s4);

        channel.notifySubscribers();

        channel.unsubscribe(s2);

        channel.setTitle("자바스크립트의 정석");
        channel.notifySubscribers();
    }

    interface ChannelObserver
    {
        void notify(String message);
    }

    // 역할을 명확히 표현하는 명사형 이름으로 수정 (Subscribe -> Subscriber)
    static class Subscriber implements ChannelObserver
    {
        private String name;

        Subscriber(String name) { this.name = name; }

        public String getName() { return name; }

        @Override
        public void notify(String message)
        {
            System.out.println(name + "님 : " + message);
        }
    }

    // 유튜브 스펠링 및 명칭 교정 (YoubeChannel -> YoutubeChannel)
    static class YoutubeChannel
    {
        // 구독자 컬렉션의 추상화 수준을 높여 구체 클래스(Subscriber) 대신 인터페이스(ChannelObserver)를 저장하도록 설계합니다.
        private List<ChannelObserver> observers = new ArrayList<>();
        private String title;
        private String name;

        YoutubeChannel(String title, String name) {
            this.title = title;
            this.name = name;
        }

        public void setTitle(String title) { 
            this.title = title;
        }

        // 추상적인 Observer 인터페이스를 구독하도록 변경
        public void subscribe(ChannelObserver o) { 
            observers.add(o); 
        }

        // 추상적인 Observer 인터페이스를 구독 해지하도록 변경
        public void unsubscribe(ChannelObserver o) { 
            if (observers.remove(o)) {
                if (o instanceof Subscriber) {
                    System.out.println(((Subscriber) o).getName() + "님이 구독을 취소하였습니다.");
                } else {
                    System.out.println("한 구독자가 구독을 취소하였습니다.");
                }
            }
        }

        public void notifySubscribers()
        {
            String message = name + "님의 채널에서 [" + title + "] 방송을 시작합니다.";
            for (ChannelObserver o : observers)
            {
                o.notify(message);
            }
        }
    }
}

[기술적 해설]
1. 추상화(Abstraction)에 의존
   - 기존의 `YoubeChannel`은 `List<Subscribe>`로 구체 클래스를 직접 저장하고 있었습니다. 
   - 객체지향 5대 원칙인 DIP(의존역전 원칙)를 지키려면, 구체적인 `Subscribe` 클래스 대신 인터페이스인 `ChannelObserver`에 의존하도록 리스트 타입을 `List<ChannelObserver>`로 선언하는 것이 훨씬 확장성이 뛰어납니다. 
   - 이렇게 하면 나중에 `Subscriber` 외에 `BotSubscriber`, `EnterpriseSubscriber` 등 다양한 형태의 옵저버가 생기더라도 `YoutubeChannel`의 코드를 전혀 고치지 않고 구독자로 등록할 수 있습니다.
2. 명명 규칙 (Naming Convention)
   - `Subscribe`는 '구독하다'라는 뜻의 동사입니다. 클래스의 객체를 대표할 때는 객체(역할 주체)를 뜻하는 명사형 단어인 **`Subscriber`**(구독자)로 작명하는 것이 바람직합니다.
   - `YoubeChannel`은 대중적인 고유 명사인 `YoutubeChannel`로 교정하여 비즈니스 로직에 통일성을 주었습니다.

[보충 문제 안내]
- 알림 순회 과정 도중에 구독을 취소하려 할 때 발생하는 동시 수정 예외(ConcurrentModificationException)를 직접 해결하는 심화 학습을 위해 [Problem4_1.java]와 모범 답안 [Answer4_1.java]를 생성하였습니다.
