[문제]
어떤 클래스의 private int age 값을 리플렉션으로 읽어보세요.

[사용자 작성 코드]
package week11.day5;

import java.lang.reflect.Field;

public class Problem2 {
    public static void main(String[] args) throws Exception {
        // TODO
        Person person = new Person("홍길동",20);

        Field ageField = person.getClass().getDeclaredField("age");
        ageField.setAccessible(true); // private 접근을 하기 위해 설정 이게 뭔지는 모르겠지만

        int age = (int) ageField.get(person);

        System.out.println("person 필드 age :" + age);
    }

    static class Person
    {
        private String name;
        private int age;

        Person(String name, int age) {
            this.name = name;
            this.age  = age;
        }

        public String getName() { return name; }
        public int getAge()     { return age; }
    }
}

[현재 코드 특징]
- `person.getClass().getDeclaredField("age")`를 사용하여 대상 객체로부터 private 필드 객체를 정확하게 찾아내었습니다.
- `setAccessible(true)`를 통해 private 접근 제어를 적절하게 해제(우회)하였습니다.
- 얻어온 `Object` 타입 필드 값을 `(int)` 캐스팅 및 오토 언박싱을 거쳐 primitive int 변수에 정상적으로 담아내었습니다.

[Better Code]
package week11.day5;

import java.lang.reflect.Field;

public class Problem2 {
    public static void main(String[] args) throws Exception {
        Person person = new Person("홍길동", 20);

        // 인스턴스(person) 대신 클래스 리터럴(Person.class)을 이용해 정보를 가져오는 것이 더 명확합니다.
        Field ageField = Person.class.getDeclaredField("age");
        ageField.setAccessible(true); 

        // get() 메서드 대신 기본형 전용 getInt() 메서드를 사용하면 형변환(Casting)과 불필요한 박싱/언박싱을 피할 수 있습니다.
        int age = ageField.getInt(person);

        System.out.println("person 필드 age : " + age);
    }

    static class Person {
        private String name;
        private int age;

        Person(String name, int age) {
            this.name = name;
            this.age  = age;
        }

        public String getName() { return name; }
        public int getAge()     { return age; }
    }
}

[기술적 해설]
1. **기본형 전용 메서드의 성능 이점 (`getInt()`)**:
   - `Field.get(Object obj)`는 모든 객체 타입을 지원하기 위해 반환 타입이 `Object`입니다.
   - 이때 자바는 primitive 타입인 `int` 값을 `Integer` 객체로 포장(Autoboxing)하여 리턴하고, 사용자는 이를 다시 `(int)`로 캐스팅해 기본형으로 언박싱(Unboxing)하게 됩니다.
   - `Field.getInt(Object obj)` 같은 전용 메서드를 사용하면 리플렉션 내부에서 이런 변환 과정 없이 메모리에서 직접 `int` 값을 읽어오기 때문에 훨씬 효율적이고 속도가 빠릅니다.
2. **클래스 메타데이터 획득 방식 (`Person.class`)**:
   - 객체 생성 여부와 관계없이 해당 클래스의 정보(설계도)를 다룬다는 것을 명시적으로 보여주기 위해, `person.getClass()` 보다는 `Person.class`와 같은 클래스 리터럴을 사용하는 것이 권장됩니다.
